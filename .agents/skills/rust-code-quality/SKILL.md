# Rust 代码质量

先读取[项目约束](../../../AGENTS.md)，理解真实调用链、所有权、失败路径和验证入口。通用规则由本技能维护，命令和交付边界以项目约束为准；读取技能不扩大任务范围或授权。

## 按需阅读

- 实现与审查先完整阅读[实现与表达](references/implementation.md)。
- 涉及运行时失败、错误传播、缺陷修复或验证证据，再完整阅读[错误与验证](references/errors-and-validation.md)。
- 公共或共享接口、类型、错误、模块、依赖或宏：使用 `rust-api-design`。
- 锁、原子、异步任务、回调、共享状态或资源关闭：使用 `rust-concurrency-safety`。
- `unsafe`、裸指针、FFI 或手工线程安全实现：使用 `rust-unsafe-safety`。
- 测试设计、修改、去重或回归证明：使用 `test-quality`。

## 工作方式

先确定被保护的不变量，再选择表达方式；不从增加包装层、换锁或堆测试开始。质量重构时，在授权范围及必要相邻边界检查同一原因的异味，说明保留的例外，不借局部问题扩展为全仓改造。

修复应恢复可观察行为并保留原始失败。按项目约束选择必要检查，不通过弱化断言、静默跳过、无界重试或新增 `allow` 掩盖缺陷。交付说明实际变更、验证结果与剩余限制。
