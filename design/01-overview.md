# 01 - 系统总览

## 1.1 系统定位

Pure-Lang 是一个**自然语言编译器**（Natural Language Compiler）。它将自然语言视为一种"高级编程语言"，通过 LLM 作为编译器后端，将用户的自然语言描述逐步编译为可执行代码、配置和完整应用程序。

核心理念：

```
传统编译器：  源代码 → 词法分析 → 语法分析 → 语义分析 → 中间码 → 机器码
Pure-Lang：   自然语言 → 意图分析 → 任务规划 → 代码生成 → 验证 → 应用程序
```

与传统编译器不同之处在于：LLM 充当了"理解"和"生成"的核心能力，而系统其余部分负责结构化调度、安全保障和上下文管理。

## 1.2 核心概念

| 概念 | 说明 |
|------|------|
| **编译管线** | 将 NL 输入经过多个阶段转换为可执行产物的流程 |
| **Agent 循环** | ReAct 模式的推理-行动循环，驱动整个编译和执行过程 |
| **工具（Tool）** | Agent 可调用的原子操作能力（读文件、执行命令等） |
| **技能（Skill）** | 可复用的能力模块，包含提示模板和工具绑定 |
| **记忆（Memory）** | 持久化的上下文管理系统，跨会话保持连续性 |
| **沙箱（Runtime）** | 受限的代码执行环境，确保安全性 |
| **Harness** | 驱动 LLM 生成代码并验证结果的基础设施层 |

## 1.4 设计原则

### 单一职责（SRP）

每个 crate 只负责一个明确的功能领域。模块边界通过 Rust 的 trait 系统严格定义。

### Trait 驱动

通过 trait 定义组件间的抽象边界，而非具体实现。好处：
- 每个 trait 可独立 mock 测试
- 可在不修改调用方代码的情况下替换实现
- 第三方可以扩展系统（自定义工具、记忆后端等）

### 异步优先

全面采用 `async/await`，基于 `tokio` 运行时。LLM API 调用、文件 I/O、进程管理均为异步操作。

### 安全沙箱

所有 LLM 生成的代码在受限沙箱中执行。系统遵循最小权限原则：工具默认无权限，需要显式授权。

### 渐进式编译

NL 输入不是一步到位地转换为代码，而是经过多个阶段逐步精炼：

```
自然语言 → 意图 → 计划 → 代码 → 验证后的产物
```

每个阶段都可以被检查、修改或回退。

### 记忆驱动

持久化上下文确保长程任务的连续性。系统维护三层记忆：
- **短期**：当前对话轮次
- **中期**：当前会话状态
- **长期**：项目知识、用户偏好

## 1.5 Crate 依赖关系

```
                   pure-lang (binary)
                        │
                     pl-cli
                        │
                     pl-agent
                    ╱    │    ╲
           pl-compiler pl-tool pl-memory
                │       │        │
             pl-skill   │        │
                ╲       │       ╱
                 ╲      │      ╱
                  pl-core
                    │
                pl-runtime
```

依赖规则：
- `pl-core` 是最底层，不依赖任何内部 crate
- 所有其他 crate 都依赖 `pl-core`
- `pl-runtime` 只依赖 `pl-core`
- `pl-agent` 是集成层，依赖除 `pl-cli` 外的所有 crate
- `pl-cli` 只依赖 `pl-agent` 和 `pl-core`
- 不允许循环依赖

## 1.6 六大核心 Trait

| Trait | 所在 Crate | 职责 |
|-------|-----------|------|
| `LlmProvider` | pl-core | LLM API 调用抽象 |
| `Tool` | pl-tool | 工具定义与执行 |
| `MemoryStore` | pl-memory | 记忆存储后端 |
| `Runtime` | pl-runtime | 沙箱执行环境 |
| `Compiler` | pl-compiler | NL→代码编译管线 |
| `Agent` | pl-agent | Agent 推理-行动循环 |
