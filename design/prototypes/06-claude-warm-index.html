设计原则

暖白纸面 · 赭橙点缀 · 低对比侧栏 · 居中阅读流。20 屏共享同一套 design token（Claude 风格暖色），覆盖现有 Pure Studio 全部功能与状态变体，作为后续 Flutter 端重构的视觉权威依据。
  • 色板：paper 暖白系 + clay 赭橙主色 + sage/ochre/rose 语义色
  • 字体：Instrument Serif 标题 / Inter 正文 / JetBrains Mono 代码与领域值
  • 布局：双栏（侧栏浅于主区），主区居中阅读流，设置页全窗口替换聊天页
  • 状态：idle / streaming / empty / no-project / 配额 / 刷新中 / 缺 key 全覆盖
基于 02 Warm Paper Neutral 微调向 Claude desktop 风格（背景更白净、赭橙更亮）。
